# flaviodeassis.com (Flávio de Assis)

Site estático e portfólio pessoal de **Flávio de Assis** (Engenheiro de Dados & Software).

Disponível em: [https://flaviodeassis.com](https://flaviodeassis.com) (ou [https://flavio-assis.github.io](https://flavio-assis.github.io))

## 🚀 Tecnologias & Estrutura

- **HTML5 Semântico**
- **Tailwind CSS** (design responsivo, paleta moderna e modo escuro/claro com persistência)
- **Lucide Icons** (ícones SVG leves)
- **Google Fonts** (Inter & JetBrains Mono)
- **GitHub Pages** + Custom Domain (`CNAME`)

## 💻 Como rodar e visualizar localmente

Qualquer servidor HTTP estático pode ser usado para visualizar a página:

```bash
# Com Python 3
python3 -m http.server 8000

# Ou com Node.js (npx)
npx serve .
```

Acesse em `http://localhost:8000`.
